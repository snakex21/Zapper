Dokumentacja Zapper DIY

Wersja firmware: 5.1.0 (USB + tryb samodzielny + warianty językowe LCD)
Autor: Maksymilian
Opis: Generator częstotliwości terapeutycznych (Clark/Rife) na platformie Arduino.

1. Lista Zakupów

  • Arduino Nano V3 (USB-C/MiniUSB) z wlutowanymi nóżkami.
  • Wyświetlacz LCD1602 (16x2, niebieski) z konwerterem I2C (czarna płytka z tyłu).
  • Enkoder KY-040 (360° z przyciskiem).
  • Płytka stykowa 400 pól (Breadboard).
  • Rezystor 1k Ohm (0.25W).
  • Kable połączeniowe: Męsko-Męskie i Męsko-Żeńskie.
  • Krokodylki na kablu (Zestaw 10 szt.).
  • Rura miedziana TWARDA (fi 15mm).

2. Schemat Montażu (Dokładne Współrzędne)

Najpierw widok 3D montażu. Arduino Nano jest osadzone na widocznej płytce stykowej A–J / 1–30. Lewa listwa Nano jest w kolumnie D, prawa w H; dzięki temu rozstaw odpowiada Nano na breadboardzie. LCD1602 i KY-040 są odsunięte od płytki, a przewody mają osobne kolorowe tory z białą obwódką, żeby były czytelne także od tyłu.

Lewy przycisk myszy: obrót • rolka: zoom • Shift albo prawy przycisk: przesunięcie • dwuklik: reset.
LCD1602 I2C
GND → a15 → Nano GND
VCC → a13 → Nano 5V
SDA → a9 → Nano A4
SCL → a10 → Nano A5
KY-040
CLK → j12 → Nano D2
DT → j11 → Nano D3
SW → j10 → Nano D4
+ → b13 → Nano 5V
GND → j13 → Nano GND
Wyjście przez rezystor
D9 jest w H5; i5 jest w tym samym połączonym rzędzie F–J
rezystor 1 kΩ: i5 → i1
j1 → czerwony krokodylek
Nano GND (D15) → b15 → czarny krokodylek
i1 i j1 są w tym samym połączonym rzędzie F–J. Dlatego przewód wyjściowy może być w j1, gdy nóżka rezystora jest w i1.
Rezystor jest fizycznie na płytce. Sekwencja montażowa: D9 / H5 → i5 → rezystor 1 kΩ → i1 → j1 → czerwony krokodylek. Zasilanie jest rozdzielone na dwa osobne otwory tego samego rzędu: LCD VCC → a13 i KY + → b13; oba łączą się wewnętrznie z Nano 5V w D13. Masa po lewej analogicznie: LCD GND → a15, czarny krokodylek → b15, a Nano GND siedzi w D15.

Schemat 2D — jako drugi widok kontrolny

Rolka myszy: powiększanie • przeciąganie lewym przyciskiem: przesunięcie • dwuklik: dopasowanie całości.
Wyjście jest pokazane wprost: pin D9 → rezystor 1 kΩ → przewód → czerwony krokodylek. Czarny krokodylek idzie z GND. Schemat traktuj jako połączenie/punkt testowy układu.

B. Podłączenie GAŁKI (Prawa strona - Kolumna J)

Użyj kabli Męsko-Żeńskich. Wpinamy w skrajną prawą kolumnę "j".

Kabel Gałki Gdzie wbić? (Współrzędna) Opis na Arduino
CLK j12 D2 — rząd 12 po prawej
DT j11 D3 — rząd 11 po prawej
SW j10 D4 — rząd 10 po prawej
GND j13 GND — rząd 13 po prawej
+ (Plus) b13 5V — rząd 13 po lewej

Plus KY-040 jest wpięty do b13. Sam przewód po wyjściu z b13 jest prowadzony w stronę kolumny C, skręca w dół przy c13 i dalej biegnie do KY-040. Nie używaj b2 — to nie jest 5V.

C. D9 + rezystor 1 kΩ + punkt wyjściowy

Tu wcześniej brakowało najważniejszego elementu na rysunku. Rezystor ma być widoczny i wpięty szeregowo za D9.

1. PIN D9:
- Przy USB skierowanym do góry D9 jest w rzędzie 5 po prawej stronie Nano.
- Ten sam elektryczny rząd po prawej stronie płytki to m.in. otwór i5.

2. REZYSTOR 1 kΩ:
- Pierwsza nóżka: i5 — połączona z D9.
- Druga nóżka: i1.
- Czyli: D9 → i5 → [1 kΩ] → i1.

3. PUNKT WYJŚCIOWY DO POMIARU:
- j1 jest w tym samym rzędzie co i1, więc dostajesz tam sygnał już za rezystorem.
- Schemat: D9 → 1 kΩ → j1 (OUT TEST).

4. MASA DO POMIARU:
- Użyj j13 (GND po prawej) albo a15 (GND po lewej).
Najpierw sprawdź sygnał na j1 względem GND miernikiem lub oscyloskopem. Ten schemat opisuje montaż i punkt testowy układu, nie połączenie z ciałem.

D. Przygotowanie Rurek (Elektrod) - Krok po Kroku

Rurki to Twoje "rączki". Muszą być bezpieczne (bez ostrych krawędzi) i czyste (dobrze przewodzić).

Potrzebne narzędzia:
  • Piłka do metalu (brzeszczot)
  • Papier ścierny lub pilnik do metalu
  • Druciak kuchenny (stalowy) lub wełna stalowa
  1. Cięcie:
    • Odmierz na rurze dwa kawałki po około 12 cm (tak, żeby rurka wystawała z zaciśniętej dłoni po 1-2 cm z każdej strony).
    • Utnij rurę piłką do metalu. Staraj się nie zgnieść rurki (nie ściskaj jej za mocno w imadle).
  2. Szlifowanie (BARDZO WAŻNE!):
    • Po cięciu krawędzie są ostre jak żyletka. Możesz się pociąć!
    • Weź pilnik lub gruby papier ścierny i zeszlifuj ostre krawędzie na zewnątrz i wewnątrz rurki na okrągło.
    • Test: Przejedź delikatnie palcem po krawędzi. Musi być gładka jak obrączka.
  3. Polerowanie (Dla lepszego prądu):
    • Rurki ze sklepu są pokryte patyną (ciemnym nalotem) lub smarem. To izoluje prąd.
    • Weź druciak kuchenny i wyszoruj rurki pod ciepłą wodą z płynem do naczyń.
    • Mają błyszczeć jak nowe monety.

3. Firmware v5

Aktualny kod: firmware/zapper_v5/zapper_v5.ino
Ta wersja działa samodzielnie z LCD i enkoderem, a dodatkowo przyjmuje z aplikacji dokładną częstotliwość i czas przez USB. Używa sprzętowego Timer1 na wyjściu D9 i nie korzysta z tone().

Wgraj plik przez Arduino IDE. Dla typowego klona Nano wybierz procesor ATmega328P i bootloader pasujący do posiadanej płytki.

Aktualny kod firmware v5.1.0

Domyślny plik firmware/zapper_v5/zapper_v5.ino ma polski interfejs LCD. Wersje językowe są generowane jako osobne szkice Arduino — każdy zawiera tylko jeden zestaw napisów. Dla alfabetów, których typowy LCD1602/HD44780 nie potrafi bezpiecznie wyświetlić, wariant używa angielskiego interfejsu LCD. Szczegóły: firmware/LANGUAGES.md.

Archiwalny firmware v4.0: firmware/archive/zapper_v4_0.ino
Stara wersja została zachowana wyłącznie jako archiwum i nie jest już kodem zalecanym do wgrania. 

/* Historyczny fragment dokumentacji v4 został celowo usunięty z wersji wykonywalnej.
   Pełny kod archiwalny pozostaje w firmware/archive/zapper_v4_0.ino. */

/*

#define CLK 2
#define DT 3
#define SW 4
#define ZAPPER_PIN 9

// --- USTAWIENIA ---
double frequency = 1.0; 
double selectedFreq = 30000.0;
double step = 1000.0;
int stepIndex = 4; 

// Czas
int selectedTimeMinutes = 7; 
unsigned long therapyDuration = 0;
unsigned long startTime = 0;
unsigned long elapsedTime = 0;

// Opcje w menu dolnym
int subMenuOption = 0; 

// Stany maszyny
enum State { MAIN_MENU, MANUAL_SETUP, MANUAL_OPTIONS, TIME_SELECT, RUNNING, FINISHED, SLEEP };
State currentState = MAIN_MENU;

// Obsługa wejścia
int lastCLKState;
unsigned long lastButtonPress = 0;
bool buttonActive = false;
bool longPressDetected = false;
bool isStopping = false; // Używane do odliczania stopu i wyłączania

// Cooldown po obudzeniu
unsigned long wakeUpTime = 0;

// Generator
unsigned long previousMicros = 0;
int outputState = LOW;

void setup() {
  pinMode(CLK, INPUT);
  pinMode(DT, INPUT);
  pinMode(SW, INPUT_PULLUP);
  pinMode(ZAPPER_PIN, OUTPUT);
  digitalWrite(ZAPPER_PIN, LOW); 

  lcd.init();
  lcd.backlight();
  lcd.clear();
  
  showMainMenu(); 
  lastCLKState = digitalRead(CLK);
}

void loop() {
  // Jeśli śpi, nie generuj fali
  if (currentState != SLEEP) {
    handleGenerator(); 
  }
  
  handleEncoder();   
  handleButton();    
}

// --- GENERATOR ---
void handleGenerator() {
  if (currentState == RUNNING) {
    if (selectedFreq < 1000.0) {
      unsigned long interval = (unsigned long)(1000000.0 / selectedFreq / 2.0);
      if (micros() - previousMicros >= interval) {
        previousMicros = micros();
        outputState = !outputState;
        digitalWrite(ZAPPER_PIN, outputState);
      }
    } else {
      tone(ZAPPER_PIN, (unsigned int)selectedFreq);
    }
  } else {
    noTone(ZAPPER_PIN);
    digitalWrite(ZAPPER_PIN, LOW);
  }
}

// --- PRZYCISK ---
void handleButton() {
  int btnState = digitalRead(SW);

  // 1. WCIŚNIĘCIE
  if (btnState == LOW) { 
    if (!buttonActive) {
      buttonActive = true;
      lastButtonPress = millis();
    }
    
    unsigned long pressDuration = millis() - lastButtonPress;

    // JEŚLI ŚPI -> IGNORUJ TRZYMANIE, CZEKAJ NA PUSZCZENIE
    if (currentState == SLEEP) {
       return; 
    }

    // LOGIKA ODLICZANIA (Dla RUNNING i MAIN_MENU)
    if (currentState == RUNNING || currentState == MAIN_MENU) {
      if (pressDuration > 500) { 
        isStopping = true; // Rozpocznij procedurę odliczania
        lcd.setCursor(0, 3);
        
        // Teksty zależne od trybu
        if (currentState == RUNNING) {
           if (pressDuration < 1500) lcd.print("ZATRZYMANIE ZA 3..  ");
           else if (pressDuration < 2500) lcd.print("ZATRZYMANIE ZA 2..  ");
           else if (pressDuration < 3500) lcd.print("ZATRZYMANIE ZA 1..  ");
           else {
             stopTherapy(); // KONIEC TERAPII
             buttonActive = false; longPressDetected = true; 
           }
        } 
        else if (currentState == MAIN_MENU) {
           if (pressDuration < 1500) lcd.print("WYLACZANIE ZA 3..   ");
           else if (pressDuration < 2500) lcd.print("WYLACZANIE ZA 2..   ");
           else if (pressDuration < 3500) lcd.print("WYLACZANIE ZA 1..   ");
           else {
             enterSleep(); // IDŹ SPAĆ
             buttonActive = false; longPressDetected = true;
           }
        }
      }
    }
    // TRYB MANUAL (Wejście w Opcje - tu bez odliczania, po prostu long press)
    else if (currentState == MANUAL_SETUP) {
       if (pressDuration > 1000 && !longPressDetected) {
          longPressDetected = true;
          currentState = MANUAL_OPTIONS;
          subMenuOption = 0; 
          showManualOptions();
       }
    }
  } 
  // 2. PUSZCZENIE
  else { 
    if (buttonActive) {
      // A. Jeśli był w SLEEP -> Obudź się (to jest ten moment "Click")
      if (currentState == SLEEP) {
         wakeUp();
         buttonActive = false;
         return;
      }

      // B. Jeśli anulowaliśmy odliczanie (w Menu lub w Terapii)
      if (isStopping) {
         isStopping = false;
         // Przywróć dolną linię
         if (currentState == RUNNING) {
            lcd.setCursor(0, 3); lcd.print("                    "); 
         } else if (currentState == MAIN_MENU) {
            showMainMenu(); // Odśwież menu żeby zniknął napis o wyłączaniu
         }
      }
      
      // C. Zwykłe kliknięcie (z COOLDOWNEM po obudzeniu)
      // Sprawdzamy czy minęła 1 sekunda od obudzenia (wakeUpTime)
      if (!longPressDetected && (millis() - lastButtonPress > 50)) {
        if (millis() - wakeUpTime > 1000) { // <-- TU JEST TWÓJ COOLDOWN
           if (currentState != RUNNING) handleClick(); 
        }
      }
      buttonActive = false;
      longPressDetected = false;
    }
  }
}

void handleClick() {
  if (currentState == MAIN_MENU) {
    if (frequency == 1.0) { 
      selectedFreq = 30000.0; currentState = MANUAL_SETUP; lcd.clear(); showManualSetup();
    } else if (frequency == 2.0) { 
      selectedFreq = 30000.0; currentState = TIME_SELECT; lcd.clear(); showTimeSelect();
    } else if (frequency == 3.0) { 
      selectedFreq = 7.83; currentState = TIME_SELECT; lcd.clear(); showTimeSelect();
    }
  } 
  else if (currentState == MANUAL_SETUP) {
    changeStep(); showManualSetup();
  }
  else if (currentState == MANUAL_OPTIONS) {
    if (subMenuOption == 0) { currentState = TIME_SELECT; lcd.clear(); showTimeSelect(); }
    else if (subMenuOption == 1) { selectedFreq = 0.0; currentState = MANUAL_SETUP; lcd.clear(); showManualSetup(); }
    else if (subMenuOption == 2) { currentState = MAIN_MENU; lcd.clear(); showMainMenu(); }
  }
  else if (currentState == TIME_SELECT) {
    therapyDuration = (unsigned long)selectedTimeMinutes * 60 * 1000;
    currentState = RUNNING; startTherapy();
  }
  else if (currentState == FINISHED) {
    currentState = MAIN_MENU; showMainMenu();
  }
}

// --- USYPIANIE I BUDZENIE ---
void enterSleep() {
  currentState = SLEEP;
  noTone(ZAPPER_PIN);
  digitalWrite(ZAPPER_PIN, LOW);
  lcd.clear();
  lcd.noBacklight(); 
  // Czekamy aż user puści guzik żeby nie obudzić od razu
  while(digitalRead(SW) == LOW) { delay(10); }
}

void wakeUp() {
  currentState = MAIN_MENU;
  wakeUpTime = millis(); // Zapisz czas pobudki (do cooldowna)
  lcd.backlight();   
  lcd.clear();
  showMainMenu();
}

// --- POKRĘTŁO ---
void handleEncoder() {
  int currentStateCLK = digitalRead(CLK);
  if (currentStateCLK != lastCLKState && currentStateCLK == 1) {
    
    // Kręcenie w SLEEP też budzi
    if (currentState == SLEEP) {
       wakeUp();
       lastCLKState = currentStateCLK;
       return;
    }

    if (digitalRead(DT) != currentStateCLK) { // W prawo
      if (currentState == MAIN_MENU) {
        frequency += 1.0; if(frequency > 3.0) frequency = 3.0;
        showMainMenu();
      }
      else if (currentState == MANUAL_SETUP) {
        selectedFreq += step;
        showManualSetup();
      }
      else if (currentState == MANUAL_OPTIONS) {
        subMenuOption++; if(subMenuOption > 2) subMenuOption = 2;
        showManualOptions();
      }
      else if (currentState == TIME_SELECT) {
        selectedTimeMinutes++; if(selectedTimeMinutes > 90) selectedTimeMinutes = 90;
        showTimeSelect();
      }
    } else { // W lewo
      if (currentState == MAIN_MENU) {
        frequency -= 1.0; if(frequency < 1.0) frequency = 1.0;
        showMainMenu();
      }
      else if (currentState == MANUAL_SETUP) {
        selectedFreq -= step; if(selectedFreq < 0.1) selectedFreq = 0.1;
        showManualSetup();
      }
      else if (currentState == MANUAL_OPTIONS) {
        subMenuOption--; if(subMenuOption < 0) subMenuOption = 0;
        showManualOptions();
      }
      else if (currentState == TIME_SELECT) {
        selectedTimeMinutes--; if(selectedTimeMinutes < 1) selectedTimeMinutes = 1;
        showTimeSelect();
      }
    }
  }
  lastCLKState = currentStateCLK;
  
  if (currentState == RUNNING && !isStopping) updateProgressBar();
}

// --- POMOCNICZE ---

void changeStep() {
  stepIndex++;
  if (stepIndex > 5) stepIndex = 0;
  
  if (stepIndex == 0) step = 0.1;
  if (stepIndex == 1) step = 1.0;
  if (stepIndex == 2) step = 10.0;
  if (stepIndex == 3) step = 100.0;
  if (stepIndex == 4) step = 1000.0;
  if (stepIndex == 5) step = 10000.0;
}

// --- WYŚWIETLANIE ---

void showManualSetup() {
  lcd.setCursor(0, 0);
  lcd.print("FREQ: ");
  lcd.print(selectedFreq, 1);
  lcd.print(" Hz      "); 

  lcd.setCursor(0, 2);
  lcd.print("KROK: ");
  if(step >= 1000) {
    lcd.print(step/1000, 0); lcd.print("kHz ");
  } else if (step < 1) {
    lcd.print("0.1 Hz");
  } else {
    lcd.print(step, 0); lcd.print(" Hz  ");
  }

  lcd.setCursor(0, 3);
  lcd.print("[PRZYTRZYMAJ=OPCJE]");
}

void showManualOptions() {
  lcd.setCursor(0, 3);
  lcd.print("                    "); 
  lcd.setCursor(0, 3);
  
  if (subMenuOption == 0) lcd.print(" [START] ZERUJ MENU "); 
  else if (subMenuOption == 1) lcd.print(" START [ZERUJ] MENU "); 
  else if (subMenuOption == 2) lcd.print(" START ZERUJ [MENU] "); 
}

void showMainMenu() {
  lcd.setCursor(0, 0); lcd.print("WYBIERZ PROGRAM:");
  lcd.setCursor(0, 1);
  if(frequency==1.0) lcd.print("> RECZNY (Manual)   ");
  else               lcd.print("  RECZNY (Manual)   ");
  lcd.setCursor(0, 2);
  if(frequency==2.0) lcd.print("> CLARK (30kHz)     ");
  else               lcd.print("  CLARK (30kHz)     ");
  lcd.setCursor(0, 3);
  if(frequency==3.0) lcd.print("> SCHUMANN (7.83Hz) ");
  else               lcd.print("  SCHUMANN (7.83Hz) ");
}

void showTimeSelect() {
  lcd.setCursor(0, 0); lcd.print("USTAW CZAS TERAPII:");
  lcd.setCursor(5, 2); lcd.print(selectedTimeMinutes); lcd.print(" MINUT   ");
  lcd.setCursor(0, 3); lcd.print("[KLIKNIJ = START]   ");
}

void startTherapy() {
  lcd.clear();
  lcd.setCursor(0, 0); lcd.print("TERAPIA TRWA...");
  lcd.setCursor(0, 1); lcd.print(selectedFreq, 1); lcd.print(" Hz");
  startTime = millis();
}

void stopTherapy() {
  currentState = MAIN_MENU; 
  noTone(ZAPPER_PIN);
  digitalWrite(ZAPPER_PIN, LOW);
  lcd.clear();
  showMainMenu();
}

void updateProgressBar() {
  elapsedTime = millis() - startTime;
  if (elapsedTime >= therapyDuration) {
    currentState = FINISHED;
    noTone(ZAPPER_PIN);
    digitalWrite(ZAPPER_PIN, LOW);
    lcd.clear();
    lcd.setCursor(5, 1); lcd.print("KONIEC!");
    lcd.setCursor(0, 3); lcd.print("[KLIKNIJ ABY WROCIC]");
    for(int i=0; i<3; i++){ tone(ZAPPER_PIN, 1000); delay(200); noTone(ZAPPER_PIN); delay(200); }
    return;
  }
  if (elapsedTime % 500 < 20) { 
    unsigned long remaining = (therapyDuration - elapsedTime) / 1000;
    lcd.setCursor(14, 0);
    if(remaining/60 < 10) lcd.print("0"); lcd.print(remaining/60); lcd.print(":");
    if(remaining%60 < 10) lcd.print("0"); lcd.print(remaining%60);

    if (!isStopping) {
      lcd.setCursor(0, 3); lcd.print("[");
      int progress = map(elapsedTime, 0, therapyDuration, 0, 18);
      for (int i = 0; i < 18; i++) {
        if (i < progress) lcd.print("#"); else lcd.print(" ");
      }
      lcd.print("]");
    }
  }
}

Włączanie i Wyłączanie

  • Włączenie: Podłącz kabel USB. Aby wybudzić wygaszony ekran, kliknij gałkę (i odczekaj 1 sekundę).
  • Wyłączenie (Uśpienie): Będąc w Menu Głównym, przytrzymaj gałkę. Pojawi się odliczanie "WYLACZANIE ZA 3... 2... 1...". Ekran zgaśnie.

Obsługa Terapii

  1. Wybór Programu: Kręć gałką (Manual, Clark, Schumann).
  2. Czas: Ustaw długość zabiegu (np. 7 min).
  3. START: Kliknij gałkę. Dopiero teraz prąd płynie!
  4. Stop Awaryjny: W trakcie terapii przytrzymaj przycisk (zobaczysz odliczanie).

Zasady Bezpieczeństwa

  • Mokre Owijki: Rurki muszą być owinięte ręcznikiem z wodą i solą.
  • Nawodnienie: Pij wodę przed i po.
  • Rozrusznik serca: Zakaz używania.
